# Skills

This repository is a **yourskills downstream**: the one repo this organization writes
its skills to, and the repo its catalog is read from.

Skills live in `skills/<name>/SKILL.md`, bundles in `bundles/<name>.yaml`. Both arrive
as pull requests — merging one is what publishes it.

This file was committed to create the default branch, because the repository was empty
and a pull request needs a base. Replace it with whatever you like; nothing reads it.
